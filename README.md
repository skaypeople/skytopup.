# SkyTopUp — Dark Anime Pink Neon

Website statis responsif untuk top up game dan layanan digital. Versi desain ini memakai tema dark anime dengan aksen pink neon dan ilustrasi anime orisinal pada `anime-hero.png`.

## File
- `index.html` — struktur halaman
- `style.css` — tampilan dark anime pink neon
- `app.js` — interaksi formulir dan navigasi versi demo
- `anime-hero.png` — ilustrasi hero anime

## Deploy
Unggah semua file di folder ini ke root repositori GitHub `skytopup`, lalu commit. Jika repositori terhubung ke Vercel, Vercel akan otomatis membuat deployment baru.

## Catatan fitur
Login/daftar, riwayat lokal, dan stok akun masih demo di browser. Pemesanan diarahkan ke WhatsApp admin. Belum ada integrasi pembayaran, penyedia top up, autentikasi online, atau database. Jangan menaruh password admin atau API secret di file frontend publik.
